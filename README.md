# ติดตาม ADR · PGx

ระบบติดตามอาการไม่พึงประสงค์จากยา (ADR) และผลตรวจยีน PGx สำหรับ Allopurinol (HLA-B*58:01) และ Carbamazepine (HLA-B*15:02) — แผนกเภสัชกรรม

## เริ่มใช้งาน

```
npm install
npm run dev
```

เปิด http://localhost:5173

สร้างไฟล์สำหรับนำไปใช้จริง: `npm run build` แล้วเปิด `dist/index.html` ผ่านเว็บเซิร์ฟเวอร์

## หน้าจอ

- **วันนี้** – คิวโทรที่ถึงกำหนด, เกินกำหนด, ผลแล็บที่รอโทรแจ้ง, Positive ที่ยังไม่ให้บัตรแพ้ยา, 7 วันข้างหน้า
- **ติดตาม ADR** – ผู้ป่วยที่เริ่มยา พร้อมช่อง W1–W9 (คลิกช่องเพื่อบันทึกผลการโทร)
- **แล็บ PGx** – ส่งตรวจยีนแล้วยังไม่เริ่มยา ติดตามผลและการแจ้งผล
- **ปฏิทินโทร** – นัดโทรรายเดือน คลิกวันเพื่อดูรายชื่อ
- **สรุปรายเดือน** – สถิติกลุ่ม 1 / กลุ่ม 2 ตามยา ผล ADR และแพทย์

ข้อมูลเก็บใน localStorage ของเบราว์เซอร์ (คีย์เดียวกับไฟล์ ADRedit.html เดิม จึงใช้ข้อมูลเดิมต่อได้หากเปิดจากเครื่อง/โดเมนเดียวกัน)
